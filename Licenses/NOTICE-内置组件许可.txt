1. ffmpeg / ffprobe —— GNU GPL version 3
-------------------------------------------------
文件与体积（字节）：
  ffmpeg   132,109,112   （arm64 与 x86_64 两切片 lipo 合成的 universal）
  ffprobe  131,753,864   （与 ffmpeg 同一构建归档）

上游（两架构各自下载静态构建后 lipo 合成）：
  arm64   ：https://www.osxexperts.net/ffmpeg81arm.zip      （ffmpeg 8.1）
  x86_64  ：https://evermeet.cx/ffmpeg/ffmpeg-8.1.2.zip     （ffmpeg 8.1.2-tessus）
FFmpeg 源码本身：https://ffmpeg.org/download.html （对应 8.1 与 8.1.2）

为什么是 GPL-3 而不是 LGPL：
两颗切片的 configure 参数里都有 --enable-gpl（x86_64 另带 --enable-version3），
按 FFmpeg 官方授权说明，带 --enable-gpl 的构建整体按 GNU GPL version 3（或更新版本）分发。
GPL-3 全文见同目录 GPL-3.0.txt。

两颗切片都**没有** --enable-nonfree，因此这份包允许分发；如有人往这两颗二进制里
加过 --enable-nonfree（例如 libfdk-aac），本通告随之失效，必须重新核对。

包内二进制自己打印的 configuration 行，逐字复制如下（可用来核对"发给我的就是这个构建"）：

【怎么自己验一遍】
在本机对包内二进制跑这几条，输出应与上面的登记逐字对应：
  <DMG 挂载路径>/SunCut.app/Contents/Resources/bin/ffmpeg -version | sed -n '1,3p'
  lipo -thin x86_64 <...>/bin/ffmpeg -output /tmp/ffmpeg_x86 && /tmp/ffmpeg_x86 -version | sed -n '1,3p'
  lipo -archs <...>/bin/ffmpeg          # 期望：x86_64 arm64
  ls -l <...>/bin/                      # 期望：与上面各处登记的字节数一致
